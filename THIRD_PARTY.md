This repository bundles several skills that were not originally authored here.
They are included under their original licenses, with attribution, so the
collection is complete and installable in one place.

| `zotero-use` | `zotero-use` skill by Vivek Gupta (bundles the `zotero-go-cli` tool from [drguptavivek/zotero-go-cli](https://github.com/drguptavivek/zotero-go-cli)) | MIT | © 2026 Vivek Gupta | Adapted for personal workflow |

Each of these skills keeps its original `LICENSE` file inside its own directory
(see `skills/<name>/LICENSE`). The original license text governs those skills.
If you distribute this repository, keep the per-skill license files intact.

The remaining skills (`agent-reach`, `source-command-travel-guide`,
`paper-search`, `sync-docs`) are original work by Charles Liu and are covered by
the repository-wide `LICENSE` file.
