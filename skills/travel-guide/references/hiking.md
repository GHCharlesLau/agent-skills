# 徒步路线详解（hiking 增强）

> 触发条件：目的地包含**徒步/穿越/环线**（古道、峰林、峡谷、山脊），或用户明确说"要徒步"。
> 只写"游览时长 2 小时"是不够的——徒步用户要的是**分段路书 + 爬升 + 导航点 + 撤退方案**。

---

## 1. 必含内容清单

| 模块 | 必含字段 |
|------|---------|
| 路线概览 | 起点 / 终点 / 总里程 / 累计爬升 / 最高海拔 / 用时区间 / 难度星级 |
| 分段路书 | 分段编号、起止点、里程、累计里程、爬升、用时、路况、导航提示 |
| 海拔剖面 | 折线图（起终点 + 最高点标注 + 纵轴刻度） |
| 导航点 | 岔路、溪流、垭口、碎石坡、需要看轨迹的位置 |
| 撤退方案 | 中途下撤点 / 最近公路 / 村口 / 联系电话 |
| 风险提示 | 信号盲区、补水点、蛇虫、落石、暴雨涨水、门票/护林登记 |
| 装备清单 | 与线路匹配（溯溪鞋/手套/头灯/护膝…） |
| 轨迹获取 | 两步路（2bulu）搜索关键词、GPX 下载提示 |

---

## 2. 分段路书表格模板

```markdown
| 分段 | 起 → 止 | 里程 | 累计 | 爬升 | 用时 | 路况与导航 |
|------|---------|------|------|------|------|-----------|
| 1 | 上坪村停车场 → 古道入口 | 1.2km | 1.2km | +60m | 25min | 水泥路+土路，入口有指示牌 |
| 2 | 古道入口 → 黑石林核心区 | 2.0km | 3.2km | +180m | 50min | 石阶+碎石，湿滑，注意脚下 |
| 3 | 黑石林 → 山脊观景台（最高点 455m） | 1.5km | 4.7km | +120m | 40min | 山脊无遮挡，风大 |
| 4 | 观景台 → 垭口（折返点） | 1.3km | 6.0km | -80m | 35min | 有明显岔路，跟轨迹走左侧 |
| 5 | 垭口 → 上坪村（环线闭合） | 2.5km | 8.5km | -260m | 60min | 下坡碎石多，护膝建议 |
```

数据来源优先级：
1. 两步路 / 六只脚 / AllTrails 的真实轨迹（最准）
2. OSM 路径 + 等高线估算
3. 游记里的经验值（标注"约"）

> 里程和爬升要给区间（如"8–9km / +300m"），不要假装精确到米。

## 4. 难度评级（统一口径）

| 星级 | 定义 | 参考 |
|------|------|------|
| ★☆☆ | 休闲：< 8km，爬升 < 200m，路面平整 | 景区步道、峰林平走 |
| ★★☆ | 中等：8–13km，爬升 200–500m，有碎石/湿滑 | 古道环线、峰林穿越 |
| ★★★ | 挑战：> 13km 或爬升 > 800m，需涉水/攀爬/夜间 | 山脊线、溯溪 |
| ★★★★ | 高强度：多日、无补给、需专业装备 | 长线穿越 |

同时给**体能门槛**一句话：如"平时能走 10km 平路即可"。

## 5. 轨迹获取与现场导航

- **两步路（2bulu）**：搜索"地名 + 徒步"，找最近 3 个月、下载量高的轨迹，导出 GPX/KML
- **六只脚 / 户外助手**：备选
- **OSM**：`https://www.openstreetmap.org/` 找路径 + 等高线
- 文档里写清楚："出发前把 GPX 导入手机离线地图（两步路/奥维/ Gaia GPS），山里有 90% 路段无信号"
- 提醒**离线地图预下载**：高德离线地图 + 轨迹文件双重准备

## 6. 安全与风险（必须写）

- **信号盲区**：说明大致范围（如"进入古道后基本无 4G，山顶偶有"）
- **补给**：起点村口小卖部、山上无补给、每人 ≥1.5L 水
- **现金**：山村可能不支持移动支付，带 100–200 元现金
- **天气**：暴雨 → 溪谷涨水/落石；大风 → 山脊；雾 → 迷路。给"下雨则改走 XX 平路替代线"的方案
- **撤退点**：中段哪里有公路/村道可下撤，最近卫生院/镇医院距离
- **门票/登记**：是否免费、是否需要护林站登记、是否限流
- **队伍**：5 人以上建议收尾员；写明集合点与最晚下撤时间（"14:00 未到垭口即原路返回"）

---

## 7. 与 HTML 的配合

- 「徒步路线详解」在 HTML 里做成 **2 个 trail 卡片**：概览徽章（里程/爬升/用时/难度）+ 分段步骤列表（时间轴样式）+ 内联海拔剖面
- 地图上叠加**红色虚线**徒步轨迹 + 图例注明"示意"
- Markdown 版放完整分段表格（可打印，供现场对照）

## 8. 交付前徒步 QA

- [ ] 里程/爬升/用时区间合理，且与地图轨迹长度量级一致
- [ ] 分段表累计里程连续（第 n 段累计 = 前 n 段之和）
- [ ] 海拔剖面最高点与文字描述一致
- [ ] 有明确的撤退方案和最晚下撤时间
- [ ] 标注信号/补水/现金/天气风险
- [ ] 装备清单具体到物品（不说"穿合适的鞋"）
