# 海外行程补充（铁路 / 巴士 / 申根 / 图片）

> 适用：欧洲、日本等非中国目的地。重点解决「OSRM/B站/GCJ-02 不适用」的问题。

## 1. 里程与验证

| 段 | 验证方式 |
|----|----------|
| 铁路 | 运营方公布里程 + 时刻表（Renfe、CP、DB、SNCF、Trenitalia） |
| 长途巴士 | 运营方里程；可用 OSRM 复核道路距离 |
| 航班 | 大圆距离，标「约」 |
| 市内 | 不需要里程，写时间与票价 |

不要把铁路段硬套 OSRM；也不要把航班算进「陆地里程」。

## 2. 铁路 / 巴士

- **提前放票**：Renfe AVE 60 天；CP 60 天；DB 180 天；SNCF 约 4 个月。
- **早鸟价差大**：AVE 同段 €20–50（早鸟）vs €80–120（临期）。
- **车站安检**：西班牙 AVE 进站有行李安检，提前 30 分钟到。
- **跨国无直达**：如 Sevilla–Lisboa 没有实用直达火车，改用 ALSA 大巴（约 6h14）。
- **行李**：廉航基础价不含托运；比价按「含行李总价」。
- **座位**：长途巴士选靠窗；火车选静音车厢需额外订座。

## 3. 申根 / 入境

- 香港特区护照：90 天免签；中国大陆护照：申根 C 签。
- **EES**：2025-10 起首次入境采集指纹/面部，机场留 30–60 分钟。
- **ETIAS**：预计 2027 年启用，出发前查欧盟官网。
- 护照有效期覆盖离境日 +3 个月，且 10 年内签发。
- **分开购票**：国际段 + 境内段至少留 4 小时；行李要重新托运。

## 4. 安全

- 巴塞罗那：兰布拉、地铁 L3、圣家堂门口。
- 马德里：太阳门、格兰大道。
- 里斯本：28 路电车、阿尔法玛、商业广场。
- 通用：背包前背、手机不放后袋、护照放贴身腰包、每天只带 €50–80 现金。

## 5. 图片（海外）

| 来源 | 用法 | 注意 |
|------|------|------|
| Wikimedia Commons | 地标首选 | 429 时限速；用标准宽度 640/1280；重试 3 次 |
| Pexels | 通用风光 | CDN 可下；搜索页可能被拦 |
| Unsplash | 备用 | 搜索 API 常 401，只能靠已知 ID |
| 官方旅游局 | 备选 | 注意授权 |

- 下载后必须 `read` 肉眼确认；标题对、图不对很常见（搜 Córdoba 返回 Alhambra）。
- 无可靠图时允许无图卡片并注明，不得用相近景点冒充。
- `credits.json` 记录 author / license / source / used。

## 6. 地图

- 默认 **Esri 卫星/地形（WGS84）**；坐标用 Wikipedia/OSM 点坐标。
- 高德/腾讯是 GCJ-02，海外不要用，除非做坐标纠偏。
- 多源回退 + 看门狗仍适用；离线提示文案保留。

## 7. 预算

- 机票按 Trip.com 含税价；酒店按双人间/晚；餐饮按 €/天。
- 明确「人均 / 2 人合计」，目标线同口径。
- 记录汇率与查询日期（如 1 EUR ≈ 8.9 HKD，2026-11）。
- 门票列「官网价」，标注 2027 可能上调 3–5%。

## 8. 闭馆与星期

逐日核对：博物馆周一闭馆、教堂周日弥撒、王宫国事活动临时闭馆、冬季缩短营业。
用「到达日 + 星期」逐条查，别只看「每天开放」。
